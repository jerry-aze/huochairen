# 火柴人 · AI 新闻桌宠（macOS）

一个待在桌面角落的小火柴人。你离开电脑的时候，它去各个新闻源抓 AI 新闻，交给 DeepSeek 挑出值得看的、去重、写成中文摘要；等你回来，它旁边弹出小卡片，也可以推送到飞书群。

## 功能
- **自动抓新闻**：RSS 和网页都能抓，每 30 分钟检查一次，等你离开 3 分钟后再去，0–8 点安静
- **AI 筛选和摘要**：DeepSeek 每轮挑出最多 3 条，写中文摘要和推荐理由
- **管理信息源**：右键就能开关、删除、添加信息源。贴链接会自动判断怎么抓；没有链接就直接写名字（如「数字生命卡兹克」），AI 会自己上网找、试抓成功才加上
- **深入浅出**：右键任意新闻，写一篇 2000～3000 字的讲解；AI 自己决定要不要上网查资料，并列出参考资料
- **飞书推送**：每天自动推 1 条，附约 250 字的精简讲解；也可以手动推单条或推全文（太长自动分条）。推送前检查链接能不能打开
- **云端每日推送**：用 GitHub Actions 每天定时抓新闻、推 1 条到飞书，电脑关机也能收到（可选）
- **3 天新闻记录**：可以翻看前几天推过的新闻
- **偏好学习，防信息茧房**：从你的点击里学口味，但重大新闻永远推，每轮留 1 个「圈外推荐」名额，偏好会随时间淡化
- **花费可控**：卡片上显示今天的 token 和花费；每天总花费上限（默认 1 元），深入浅出每篇有查资料次数和 token 上限
- **动画状态**：抓新闻时从小黑洞里掏报纸看，写讲解时从虚空拽出黑板写字，头顶指示灯显示忙 / 有新闻 / 成功 / 失败

## 安装
需要一台 Mac 和一个 [DeepSeek API Key](https://platform.deepseek.com/)。

1. 下载本仓库
2. 双击 `启动.command`，第一次会自动安装依赖（需要 Python 3）
3. 小火柴人出现后，按提示粘贴 DeepSeek API Key（只保存在你自己的电脑上，`~/.ai_news_pet/`）
4. 可选：运行 `制作启动图标.sh` 生成可以双击的「火柴人.app」

详细用法见 [使用说明.md](使用说明.md)。

### 可选：云端每日推送（电脑关机也能推飞书）
1. Fork 或使用本仓库，进入 Settings → Secrets and variables → Actions，添加：
   - `DEEPSEEK_API_KEY`：DeepSeek 的 Key
   - `FEISHU_WEBHOOK`：飞书群机器人的 webhook 地址
   - `FEISHU_SECRET`：飞书机器人的签名密钥（没开签名校验就不用加）
2. 在 Actions 页面打开「每日飞书推送」，点 Run workflow 试跑一次
3. 之后每天自动运行（时间在 `.github/workflows/daily-feishu.yml` 里改）

`config.json` 里 `"feishu_auto_push": "cloud"` 表示每日推送交给云端；不用云端的话改成 `"desktop"`，由桌面火柴人自动推。

## 设置
所有设置都在 `config.json`：检查频率、免打扰时段、每次推几条、想看什么（`interests`，最值得改）、信息源、各种花费上限等。信息源更推荐用右键「管理信息源」改，改完立即生效。
