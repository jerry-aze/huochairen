# 火柴人 🕴️

一个住在 Mac 桌面右下角的小火柴人。你离开电脑的时候，它会去各大 AI 新闻源抓新闻，交给 DeepSeek 挑出真正值得看的、去重、写成中文摘要；等你回来，它举手挥舞，旁边弹出新闻卡片。

- 📰 **自动抓 AI 新闻**：OpenAI、Anthropic、Google DeepMind、Hacker News、机器之心、量子位……
- 🤖 **DeepSeek 筛选 + 中文摘要**：每轮最多挑 3 条，同一件事只留一条，营销软文和标题党直接过滤
- 💡 **不打扰**：等你离开电脑再去抓，0～8 点免打扰，状态全靠头顶的呼吸灯
- 📖 **深入浅出**：右键任意新闻，让它读原文、写一篇 2000～3000 字的讲解，把这条新闻给你讲明白
- 💬 **飞书推送**（可选）：每天自动推 1 条最重要的到飞书群，也可以右键一键推送任意一条
- 📊 **Token 监控**：随时看今天 / 本月花了多少 token、多少钱、账户余额
- 🧹 **自动清理**：每周一清理日志和过期文章，不会越用越占地方

> 目前只支持 **macOS**（用到了 Mac 的空闲检测和应用打包）。

## 安装

**需要准备**：一台 Mac，一个 [DeepSeek 开放平台](https://platform.deepseek.com) 账号（充几块钱，一天大约花几分钱到一两毛）。

1. 下载本仓库（右上角 **Code → Download ZIP**），解压到任意位置，比如「文稿」。
2. 打开「终端」，进入解压后的文件夹，运行一次：
   ```bash
   bash 制作启动图标.sh
   ```
   文件夹里会生成一个「**火柴人**」应用。
3. 双击「火柴人」。第一次会弹出终端窗口自动安装依赖（1～3 分钟），装好后右下角出现小火柴人，并弹窗让你粘贴 DeepSeek API Key。

> 如果 macOS 提示需要安装「命令行开发者工具」或 Rosetta：前者点「安装」，装完再双击一次；后者点「以后」即可。

Key 只保存在你自己电脑的 `~/.ai_news_pet/` 里，不在项目文件夹中。

## 使用

| 操作 | 效果 |
|---|---|
| 拖动小火柴人 | 换位置 |
| 单击它 | 看新推送 / 今天的新闻 |
| 新闻卡片：双击 | 打开原文 |
| 新闻卡片：右键 | 深入浅出、推送到飞书、打开原文 |
| 右键小火柴人 | 立刻抓一次、Token 用量、设置 Key / 飞书、呼吸灯说明、重启、退出 |

**头顶的呼吸灯**：🟢 待命　🟡 正在抓新闻 / 写深入浅出　🔵 抓完了，没有新新闻　🟣 出了问题（鼠标停在小人上看原因）　🔴 + 数字 有新闻没看

更详细的说明见 [使用说明.md](使用说明.md)。

## 设置

改 `config.json`，然后右键小火柴人 →「重启火柴人」：

| 设置 | 默认 | 说明 |
|---|---|---|
| `interests` | 大模型、研究、产品、行业大事 | **最值得改**：用大白话写你想看什么、不想看什么 |
| `sources` | 7 个 AI 新闻源 | RSS 或网页；不要的源加 `"enabled": false` |
| `check_every_minutes` | 30 | 多久检查一次 |
| `idle_minutes_before_fetch` | 3 | 你离开多久后再去抓 |
| `max_news_per_push` | 3 | 每轮最多推几条 |
| `quiet_hours` | `[0, 8]` | 免打扰时段 |
| `feishu_daily_limit` | 1 | 飞书每天自动推几条 |
| `explain_keep_days` | 30 | 深入浅出文章保留几天，`0` = 永久 |
| `model` / `base_url` | `deepseek-flash` | 也可以换成其他兼容 OpenAI 接口的模型 |

想调整「深入浅出」的写法，直接改 `深入浅出.md`。

## 飞书推送（可选）

1. 用**电脑版飞书**建一个群（只有你自己也行）→ 群设置 → 群机器人 → 添加机器人 → 搜「自定义机器人」→ 添加，复制 webhook 地址（建议开启「签名校验」）。
2. 右键小火柴人 →「设置飞书推送」，粘贴地址和签名密钥，它会自动发一条测试消息。

## 开机自动启动

系统设置 → 通用 → 登录项 → 点「+」→ 选「火柴人」。
